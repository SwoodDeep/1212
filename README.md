# APEX CIRCUIT 3D

Полноценная браузерная 3D-гонка (Three.js + TypeScript + Vite). Запускается локально, все ассеты включены в проект.

## Запуск

```bash
npm install
npm run dev        # сервер разработки -> http://localhost:5173
```

Продакшен-сборка и превью:

```bash
npm run build
npm run preview    # -> http://localhost:4173
```

Тесты:

```bash
npm test           # юнит-тесты игровой логики (vitest)
node tests/e2e.mjs medium 60   # E2E-прогон в headless Chromium (нужен playwright)
```

## Управление

| Клавиша | Действие |
| --- | --- |
| W / ↑ | газ |
| S / ↓ | тормоз / задний ход |
| A, D / ←, → | руль |
| Space | ручной тормоз (управляемый занос) |
| Shift | нитро |
| C | смена камеры (3 режима: сзади / ближе / «капот») |
| R | вернуть машину на трассу |
| Esc / P | пауза |
| Геймпад | стик — руль, RT/LT — газ/тормоз, A — ручник, X — нитро, Start — пауза |

## Режимы

- **Гонка** — 3 круга против 4 AI-соперников с разным уровнем сложности.
- **Заезд на время** — 3 круга соло, рекорд сохраняется локально.

## Возможности

- Трасса ~1.4 км: сплайн Catmull-Rom с перепадами высот, асфальт с PBR-текстурами (Poly Haven), красно-белые поребрики, гравийные обочины, шахматная линия старта.
- Окружение: террейн-«холмы» вокруг трассы, instanced деревья/камни (8 видов деревьев, 6 видов камней), барьеры, фонари, стартовый мост, трибуна, билборды, конусы на апексах, деревня с домами.
- 5 машин (Kenney Car Kit, CC0) с разными характеристиками; вращающиеся и поворачивающиеся колёса, визуальная подвеска, крен/тангаж кузова.
- Аркадная физика с фиксированным шагом 120 Гц: разгон/тормоз/задний ход, инерция, сцепление, занос с ручником, нитро, столкновения со стенами и между машинами, восстановление на трассу (R).
- AI: гоночная линия по кривизне трассы, торможение перед поворотами, избегание столкновений, обгоны, резиновая нить к игроку, восстановление при застревании.
- Гоночная логика: обратный отсчёт, 8 чекпоинтов на круг, круги, позиции, таймеры круга/гонки, лучший круг, экран результатов, пауза, рестарт.
- HUD: цифровой спидометр, передача, круг, позиция, время, лучший круг, нитро-индикатор, миникарта, сообщения («Финальный круг», «Едешь не туда»).
- Звук (Web Audio API): синтезированный двигатель по оборотам + реальный луп мотора, визг шин, ветер, удары, отсчёт, UI — часть сэмплов скачана (CC0).
- Эффекты: следы шин (кольцевой буфер, 1 draw call), дым/пыль/искры/нитро-пламя (пул частиц), тряска камеры, FOV-эффект скорости, виньетка.
- Графика: HDRI-небо (Poly Haven) + PMREM-окружение, солнце с föllow-тенями, туман, ACES тон-маппинг, опциональный bloom.
- Оптимизация: instancing всех повторяющихся объектов, объединение статической геометрии, пул частиц, фиксированный шаг физики, spatial-hash для запросов к трассе, пресеты качества **Low / Medium / High** (pixel ratio, тени, дальность тумана, количество деревьев/частиц, HDRI, bloom) + автоподбор по FPS. ~110–160 draw calls, ~220k треугольников на Medium.

## Структура проекта

```
index.html            точка входа
src/
  main.ts             инициализация, debug-хуки (window.__game)
  config.ts           трасса, машины, AI-уровни, пресеты качества, пути ассетов
  core/               Game (состояния/цикл), Input (клавиатура+геймпад)
  track/              TrackDef (сплайн, запросы), RacingLine, TrackMesh (мир), PropInstancer
  car/                Vehicle (физика), CarEntity (модель, колёса, подвеска)
  ai/                 AIController (гоночная линия, обгоны, избегание)
  race/               RaceManager (круги, чекпоинты, позиции, таймеры)
  render/             Renderer, Sky (HDRI, солнце, туман)
  effects/            Particles, SkidMarks, CameraRig
  audio/              AudioEngine (Web Audio)
  ui/                 UI (меню/HUD), styles.css
  utils/              math, storage
public/assets/        модели (GLB), текстуры, HDRI, звуки, частицы (все локально)
tests/                vitest (логика) + e2e.mjs (headless Chromium)
tools/                скрипты скачивания ассетов (kenney.mjs, ph.mjs, probe.mjs, glbinfo.mjs)
```
